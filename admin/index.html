👥 Personnes

Une ligne par personne. Un encadrant (issu des projets) a un code par défaut 000000 qu'il change à sa 1ʳᵉ connexion ; vous pouvez le réinitialiser (retour à 000000). Un opérateur a un code à 6 caractères saisi par l'admin, des machines et un contact WhatsApp. Le rôle Achat désigne un gestionnaire des commandes (encadrant ou opérateur) ; un opérateur « Achat » disposant d'un WhatsApp reçoit les notifications de nouvelles demandes. Clique les pastilles Opérateur / Achat d'une ligne pour activer/retirer un rôle. Une personne peut cumuler les rôles.
