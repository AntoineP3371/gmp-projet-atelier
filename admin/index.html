👥 Personnes

Une ligne par personne. Chaque personne a un seul code, partagé entre ses rôles encadrant et opérateur : elle le choisit elle-même à sa 1ʳᵉ connexion (code par défaut 000000, au moins 4 caractères libres). L'admin ne saisit pas le code — il peut seulement le réinitialiser (retour à 000000 pour les deux rôles). Les colonnes « Code encadrant » et « Code opérateur » indiquent l'état du code pour chaque rôle. Le rôle Achat désigne un gestionnaire des commandes (encadrant ou opérateur) ; un opérateur « Achat » avec WhatsApp reçoit les notifications. Clique les pastilles Opérateur / Achat pour activer/retirer un rôle. Une personne peut cumuler les rôles.
